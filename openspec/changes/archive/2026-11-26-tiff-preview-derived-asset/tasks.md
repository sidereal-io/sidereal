<!-- Dated notes on small departures from the plan, written during apply. Stop and ask the user about a large one. -->

- 2026-11-25, task 1.1: the plan names no media type for the astro pack's plate-solve stub, which must now declare one. It accepts `image/fits`, the registered media type for FITS (RFC 4047). The stub still never runs.
- 2026-11-25, task 3.1: the `ImageFormat` trait also has `signatures()`, the signatures a format starts with, and provides `probe_len()` and `matches()` from it. The unit test in `formats/mod.rs` needs the signatures to check that no format matches another's. `ImageInput` has only `read_at`, as planned: `CandidateReader::new` takes the input's size beside it.
- 2026-11-25, task 3.2: the server test `upload_of_unsupported_bytes_answers_415_naming_png_and_jpeg` listed TIFF bytes as refused. Now that the pack takes TIFF, a GIF replaces that case, so the suite stays green. Task 4.1 rewrites the test for the new 415 body.
- 2026-11-26, task 3.3: the supervisor is a thread, not an async task. The runner is called from core's blocking worker, and a thread can kill and reap the helper while the runner is blocked in a write. The upload's async wait for the slot is `WorkerRunner::admit`. The upload starts calling it in task 4.1, when the preview Operator joins the upload; until then no upload runs a preview.
- 2026-11-26, task 3.3: the helper takes `--budget BYTES`, which can only lower the budget, and `--self-check describe|zeroed|grow|fits|stall`. The suite uses them to measure the stack and heap and to test the allocator and the liveness pipe in the real helper. Shell scripts stand in for a helper that stalls, closes its output or fails part way.
- 2026-11-26, task 3.3: the stalled-copy test runs at the runner, with no database. A later preview runs to the end and the host reads a file while the first copy is blocked. The test does not serve an original download through the server.
- 2026-11-26, task 3.4: the code came before its tests. The tests were then checked by breaking the separate-scan refusal, the marker walk and the PNG `IEND` check one at a time: each break failed the tests that cover it.
- 2026-11-26, task 3.4: `ImageFormat::render_preview` takes the input and its size, not one `CandidateReader`.
