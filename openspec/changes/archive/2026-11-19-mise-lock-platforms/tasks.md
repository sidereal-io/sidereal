## 1. The lock platform check

- [x] 1.1 [medium] `scripts/check-mise-lock-platforms.sh` exists, is executable (git mode 100755), and exits 0 on the committed `mise.lock`, where every `[[tools.*]]` entry except `[[tools.rust]]` has `linux-x64`, `linux-arm64` and `macos-arm64` tables. Run at the repo root with no argument, it reads `mise.lock` there; with one argument, it reads that file. The required platforms and the exception list (`rust`) are one variable each (design Decisions 2 and 3) (verify: `scripts/check-mise-lock-platforms.sh && test "$(git ls-files -s scripts/check-mise-lock-platforms.sh | cut -c1-6)" = 100755`) (✓ red: script missing, exit 127; green: verify command passed)
