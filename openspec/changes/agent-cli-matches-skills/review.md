## Findings

The author verified each finding against the repo. The verification follows each one.

### 🔴 Critical (blocking)

1. **The check races with skill regeneration.** While `just enter` regenerates the skills, the stamp doesn't exist for about a second. An agent session that starts in that window gets a "no generated skills" report.
   - *Author verification:* CONFIRMED as a scenario, disputed as critical. direnv finishes the shell hook before the prompt returns, so an agent started from that terminal can't hit the window. Only an agent started from another window during regeneration can. The report is then accurate: the skill folders were deleted too, so the agent really started without them. The `skills-on-env-enter` change accepted the same race (its D6).
2. **Stamp text flows into the agent's context without sanitising.** A modified `.agents/skills/.openspec-stamp` could carry instructions into the report.
   - *Author verification:* CONFIRMED as cheap hardening, disputed as critical. Anyone who can write the git-ignored stamp can also write the git-ignored `SKILL.md` files, which the agent reads directly. The check opens no new route. Printing only version-shaped text still costs little.

### 🟡 Moderate

3. **`set -euo pipefail` breaks "exit 0 in every case".** If `openspec --version` fails, the script exits non-zero.
   - *Author verification:* CONFIRMED. `scripts/skills.sh` line 7 sets the flags, and `current_inputs` runs the CLI in a command substitution.
4. **Two agent-session scenarios can't be asserted by a script.** "The agent can state both versions when asked" needs a model to answer.
   - *Author verification:* CONFIRMED.

### 📌 Suggestions

5. **Passive voice hides the actor** in "the skills were generated by one `openspec` version" and in the scenario name "No skills were generated". — CONFIRMED.
6. **One sentence has 31 words** in the requirement "Contributors learn how to start an agent". — CONFIRMED.

The reviewer could not verify the claims about Claude Code and Codex hook behaviour. The design already gives the Codex claims to a verification task.
